## Description

`HUD_GetStudioModelInterface` returns 0, so the engine's default renderer draws every model.

TS overrides `StudioSetupBones` (`0x10031080`) so the upper body splits at `"Bip01 Dorso"` (or
`"Bip01 Spine"`), with a torso yaw fix. It also scales gait by framerate and does corpse/ghost draws.
Without this, run-and-aim, akimbo and stunt animations don't blend the way TS shows them.
