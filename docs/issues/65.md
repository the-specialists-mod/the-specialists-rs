## Description

**Missing cvars.** TS registers these client cvars (decomp `architecture-hud.md` §2.1), but the port never does:
- `CAM_Init`: `cam_command cam_snapto cam_idealyaw cam_idealpitch cam_idealdist cam_contain c_maxpitch c_minpitch c_maxyaw c_minyaw c_maxdistance c_mindistance`
- `CHud::Init`: `gl_fog_start gl_fog_end gl_fog_red gl_fog_green gl_fog_blue`
- `V_Init`: `scr_ofsx scr_ofsy scr_ofsz`
- `Scheme_Init`: `bitmapfonts`

Configs that set them get "unknown command", and `cvarlist` differs from TS. Register each once, where TS registers it, following the single `goldsrc::client::Cvar` rule from #60. Or record why not under Deviations in `client-hud.md`.

**`gl_fog 2`.** TS `V_SetFog` (0x10056c20): when `GetMaxClients() == 1` and `gl_fog == 2`, the fog colour comes from the user cvars `gl_fog_red/green/blue`, and linear fog from `gl_fog_start` / `gl_fog_end`. Otherwise it uses the map's `ts_fog` when `gl_fog != 0`. `effects::fog_begin` implements only the map-fog branch. Port the first branch through `tri::fog`, or note it under Deviations in `client-rendering.md`.
