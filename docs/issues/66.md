## Description

`Knife::think` in `crates/server/src/weapons/projectiles.rs` scales velocity and spin by 0.5 every 0.1 s while a stuck knife is on the ground. TS `CTSKnife::WaitThink` (0x7ea30) has no such scaling.

`CTSKnife::WaitTouch` (0x7dce8), already ported as `Knife::wait_touch`, halves velocity on each ground touch. The engine runs that touch every frame while the knife slides: neither FWGS `SV_Physics_Toss` nor ReHLDS `SV_Physics_Bounce` slows a sliding bounce entity on its own (see the #64 note in `docs/implementation/weapons.md`). So the extra think friction is probably redundant.

Fix: remove it, check in-engine, and remove the "Stuck knives keep a port-only ground friction" line from the Deviations in `weapons.md`.
