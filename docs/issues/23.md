the ReHLDS source, a listen server only pauses like this in single-player mode (`maxplayers 1`),
when the menu or console sends `setpause` (`Host_Pause_f`, guarded by `pausable`). Confirm which
max players setting was used, and whether `pausable 0` or `maxplayers >= 2` clears it.

To check:
- The listen server starts unpaused.
- MOTD → buy menu → click to spawn, with the client-side mouse path (`input.rs` native module).
- HUD, prediction and effects on the Steam renderer.
- The `cl_enginefunc_t` layout differences on the Steam engine (see `docs/ts-patcher.md` in the parent workspace: `DrawString` at +0x1C8).

- Server-sent view angles were ignored while a menu cursor was up.

- Third person stayed on after every respawn.
- `addbot` spammed "no free client slot" on a full server.

**Other results:**
- **FWGS dedicated:** can't accept the Steam client (FWGS servers only take protocol 49; Steam is 48).
