## Description

`DrawCrosshairID` (1004acc0) calls `EV_PlayerTrace(start, end, 2, localIndex, &tr)` and then calls `EV_IndexFromTrace` whether or not the trace hit anything.

The port (`ClEngine::crosshair_trace`) passes `ignore_pe` -1, and only looks up the index when the fraction is below 1.

`ignore_pe` is a physent index, not an entity index, so TS's value may be a quirk that skips an unrelated physent. Decide whether to port it as TS does, or record it under Deviations in `docs/implementation/client-hud.md`.
