## Description

Found in the deviation audit (checked in `client.dll` and the port):

1. **Client bullets.** TS updates and draws them at the end of `TS_DrawEffects` (0x10034e60 → 0x10035b50). Updates are throttled by `0x1018d16c`, and `0x10035010` draws a slow-motion sprite when ts < 0.99. The port steps them in `HUD_CreateEntities` (`crates/client/src/events/fire.rs`) and draws no slow-motion bullet sprite.
2. **Fire sound sample.** TS picks `info+0x306` or `+0x2c6` by the silenced flag alone (0x1003de98/0x1003dee5). The port falls back to sound1 when sound2 is empty, and skips empty samples (`fire_sound`).
3. **Fog.** TS calls raw `glDisable(GL_FOG)` (0x10056e5e), which also switches off the engine's own fog, e.g. under water. The port goes through TriAPI `Fog`. Add a raw-GL wrapper in `goldsrc` and match TS.
4. **Stale doc.** Check the `FL_DUCKING` note in `docs/implementation/client-rendering.md` (~line 280) against the weapons audit (58d891f), which now reads the gun entity's own flags.
