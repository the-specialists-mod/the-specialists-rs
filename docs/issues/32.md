## Description

TS `DoSpectacularNess` (0x76b48) clamps `spectacularness` to 0–100 and rounds it. It never fires when the value is 0; otherwise it fires when `RandomLong(0,100) <= value`.

The port's `spectacular()` (`crates/server/src/rules/scoring.rs`) compares the roll with the raw float. So `spectacularness 0` (or something like 0.4) still fires on a roll of 0, about 1 time in 101, and a frag can create a slow-motion point on a server that turned the feature off.

The weapons work for #18 adds an exact `do_spectacularness()` in `crates/server/src/weapons/projectiles.rs`; share it here.
