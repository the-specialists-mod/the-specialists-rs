# #52: goldsrc ext/hud.rs still keeps hand-written mirrors of triangleapi_s and demo_api_s

## Description

`crates/goldsrc/src/ext/hud.rs` declares `TriApiPrefix`, a hand-written prefix of `triangleapi_s` up to `WorldToScreen`. bindgen already generates the full `triangleapi_s`, and `ext/render.rs` / `ext/tri.rs` use it.

There are two `WorldToScreen` wrappers, and they handle a null slot differently:
- `ClEngine::world_to_screen` (TS `WorldToScreen` 0x100579c0) returns `None`.
- `render::world_to_screen`, used by `effects/laser.rs`, panics.

`DemoApi` is hand-written too, because `goldsrc-sys/build.rs` doesn't include `demo_api.h`. FWGS has it at `common/demo_api.h`, so adding it to the `render_ext.h` `header_contents` and allowlisting `demo_api_t` would remove the need for `DemoApi`. `ClEngine::server_cmd` and `render::server_cmd` are also duplicates.

Fix: switch to the bindgen structs and keep one wrapper for each call. This follows #44, which did the same for `event_api_s`.
