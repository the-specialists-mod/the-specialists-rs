## Description

`CTSFlag` has `ObjectCaps` 0x10 (0x9e704) and `CanUsedTroughWalls` 0 (0x9e70c). Its `Use` (0x9e5dc) calls `PlayerTakeFlag` (around 0x9e420).

In the port, `ctb::Flag` (`crates/server/src/entities/ts/ctb.rs`) takes the case only on touch: it has no `Entity::use_` or player-use hook. The unified `player::player_use` from #34 picks the flag as the +use target and then nothing happens.

Fix: add a `use_by_player` branch that runs the same take logic as the touch.
