## Description

Several client values were approximated and need comparing side by side with the original TS client
(`~/games/xash_win_orig`):
- **Recoil:** the view climbs steeply under sustained fire. Each shot's kick is applied once
  (`view::kick`), so this is probably TS's persistent recoil (`CTSGun::VKickback` `0x80414`
  changes view angles, not `punchangle`), but it hasn't been compared.
- **Particles:** per-effect sizes, speeds and lifetimes in `effects::fx` were tuned by eye. The
  `TS_GunSmoke` count is treated as an intensity. The react (player push) formula is inferred.
- **Whizz:** the volume formula is approximated.
- **Divesteps:** the sprite availability thresholds (used slots < 42/52/62) come from a garbled decompile.

- Port notes: `docs/implementation/client-rendering.md`, `docs/implementation/client-hud.md` §8, `docs/implementation/integration.md` §5, `ts30-decomp/docs/server/weapons.md` §5.3
