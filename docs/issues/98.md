## Description

Found while working on #91 (checked in `client.dll` and the port):

1. **Material sound.** TS's impact-sound function plays the material sound when `RandomLong(0,100) > 33` (the roll is at 0x10044c2a, the compare at 0x10044ff8). The port tests `dmg > 33.0` and skips the roll (`crates/client/src/events/impact.rs`), which also shifts the random-number sequence.
2. **Penetration in `EV_TS_FireBullets`.** TS uses the global remaining damage `DAT_1018a164` (set only on a hit, never reset, so it carries over between calls) and the last trace's end point, even when the last pellet missed (0x10045c00 onward). The port needs the last pellet to hit, and uses that call's damage (`crates/client/src/events/fire.rs`).
