## Description

Found while working on #96 and #97 (checked in `ts_i386.so` and the port; Ghidra addresses and decomp files):

1. **Thrown-knife names.** TS names the blade with `CTSKnife::GetDescription` (0x7db04): "Throwing Combat Knife", "Throwing Seal Knife" or "Throwing Katana". The port says "Throwing Knife" in `scoring.rs` `weapon_name`, and "Throwing" in `points_for_frag`. The knife object isn't reachable during its own touch while the kill is scored, so this needs a way to read it.
2. **` (victims_weapon)` log suffix.** TS adds it in `PlayerKilled` (0x895e4) when the killer's gun originally belonged to the victim (gun+0x30). The port doesn't track a gun's original owner, so `log_kill` never writes it.
3. **ScoreInfo in entity code.** It still clamps frags instead of keeping the low 16 bits. TS uses the `(int)` cast in `CTSFlag`/`CTSBriefcase` (CTSFlag.c:461, CTSBriefcase.c:249) and `CTSDMHill` (CTSDMHill.c:219, 250). Port: `entities/ts/ctb.rs`, `entities/ts/triggers.rs`; use `lifecycle::score_frags`.
4. **`g_vecAttackDir` writers.** In TS, monsters' `DeadTakeDamage`, `CBreakable` (CBreakable.c:1066, 1271) and `CBaseEntity::TakeDamage` (CBaseEntity.c:95) also write it. The port's `entities/stock/monsters.rs` and `breakable.rs` use their own local directions, so `damage::attack_dir` can be stale where TS's isn't. Also drop `multi::add`'s unused fifth argument (`breakable.rs`).
5. **`CTSGameRules::Init` resets.** On every map, TS's Init resets `armor_absorb`/`health_absorb` (`+0x588c`/`+0x5888`) and the custom-weapons flag (`+0x5884`) (`CTSGameRules.c:428-434`). The join HUD only announces custom weapons while that flag is set (`CTSGameRules.c:1100`). The port keeps these in `shared::weapons::table`, which is never reset (read at `player/damage.rs` and `weapons/custom.rs`).
6. **Latched `sv_cheats`.** `weapons/assets.rs` (`damagemult`, `dmgreport`) reads `sv_cheats` live. TS uses the value latched at map load (`CBulletManager.c:316,331`; `CBasePlayer.c:221,240`); #97 added that latch.
7. **Remaining #97 deviations.**
   - `game_player_team` still defers when the activator is mid-dispatch through a TS item pickup or its own weapon frame.
   - The spray can and the blood splat are removed at the end of the frame, not straight away.
   - Impulse 105's no-player-sound flag has no effect until `soundent` exists (#95).
