## Description

Five differences between TS's \`AddToFullPack\` (0xaf180, \`server/decomp/global_000ab05c.c\` from line 1795) and the port's \`add_to_full_pack\` (\`crates/server/src/net.rs\`). Each was checked against both sides. Found while working on #68.

1. **Hiding entities.** TS hides an entity only when \`effects == 0x80\` (exactly \`EF_NODRAW\`, nothing else set). The port (\`net.rs:23\`) hides it whenever the \`EF_NODRAW\` bit is set.
2. **Group filtering.** TS filters by \`groupinfo\`. When the host's \`groupinfo\` is set, it calls \`UTIL_SetGroupTrace\` and skips the entity based on \`g_groupop\` (0 = AND must match, 1 = NAND). The port doesn't filter by group at all.
3. **eflags.** TS sets \`eflags |= 1\` for a non-player with \`animtime != 0\`. The port (\`net.rs:79\`) uses the SDK's \`FL_FLY\` test instead.
4. **Render values.** TS rounds \`renderamt\` and \`rendercolor\` (\`ROUND\`). The port truncates them (\`net.rs:66-68\`).
5. **weaponmodel.** TS sends players' \`weaponmodel\` as \`pfnModelIndex(pev->weaponmodel)\`. The port always sends 0 (\`net.rs:97\`), even though \`delta.lst\` sends the field.
