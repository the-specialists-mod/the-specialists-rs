# #53: Player HUD health/armour bytes are rounded and capped; TS truncates

- State: closed (completed)
- Labels: bug, integration

- Originally CrunchyMonkies/rust-hlmod-the-specialists#53

## Description

TS `CBasePlayer::UpdateClientData` (0x91d00) sends `(int)max(health, 0)` (truncated at 0x91fd2) and `(int)armorvalue` (0x9206e / 0x920c0) as a plain byte, with no cap at 255.

`update()` in `crates/server/src/player/hud.rs` (around line 53) uses `.round().min(255.0)` for both. So health that isn't a whole number (The One's regen of n×0.16, fall damage) can show one point higher than in TS.

Fix: truncate (e.g. `as i32 as u8`).
