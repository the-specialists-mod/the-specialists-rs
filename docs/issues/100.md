## Description

Found while working on #92 (checked in `client.dll` and the port):

1. **Geiger.** `CHudGeiger::Draw` (0x1001f4e0) plays `player/geiger%d.wav`. The port ignores `Geiger` (the `Msg::Geiger` no-op arm in `crates/client/src/hud/state.rs`). The HudText flicker shares MSVC `rand` with these sounds, so once they're ported the flicker sequence matches too.
2. **Scoreboard last killer.** `ScorePanel::DeathMsg` (0x1005e5d0, called via 0x10065230) records who last killed the local player. The port has nothing equivalent in `menus/scoreboard.rs`.
3. **Localisation.** `text::localise_with` (`crates/client/src/hud/text.rs`) differs from TS's 0x100348d0 in which characters count as part of a `#word`, and in having no length budget. It's used for TextMsg, ShowMenu and TSMessage. Use TS's rules everywhere.
4. **Player names.** Names that aren't UTF-8 are converted lossily (`crates/goldsrc/src/ext/hud.rs`, `to_string_lossy`), so they show as `?` in the kill feed, status bar and chat. TS passes the raw bytes through.
