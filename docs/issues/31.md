## Description

TS `V_SmoothStairs` (0x100677d0, confirmed in the assembly) works on the eye height (position plus smoothed view height):
- On the ground it eases the smoothed z at `min(15·ft, 1)` and zeroes the offset.
- On the frame it leaves the ground it sets `offset = z − smoothZ`.
- The output is `smoothZ + offset`, and the offset decays at rate 15.

The port (the stair block in `view::calc_normal`, `crates/client/src/view.rs`) differs:
- It smooths the player position, not the eye.
- It uses the opposite sign (`smooth_z − simorg.z`).
- It adds a 32-unit snap that TS doesn't have.

TS's sign looks like it would push the eye up when leaving a step, so compare in game before copying it. Either way, the "done" status in `docs/implementation/client-rendering.md` is inaccurate.
