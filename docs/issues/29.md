## Description

In TS, `CTSGroundWeapon::GetWeapon` (0xa2328) calls `CTSGun::AddAmmo` for `wextraclip` only when the player's reserve for that ammo type is below 1.

The port (`GroundWeapon::give` in `crates/server/src/entities/ts/ground.rs`) always gives `extra × clip`, so a player who already carries that ammo gets more. `rules.md` §6 documents only the difference in amount, not this missing check.
