# #63: Kevlar slot weight bypasses the shared free-slot count and is lost on the next weapon change

- State: closed (completed)

## Description

TS `CBasePlayer::TakeArmor` (0x93da4) takes 10 from `pl+0x548`, the free-slot count that weapons share (`PickUpWeapon` 0x9314c), and gives the 10 back when the armour is removed.

The port has two versions: `rules/powerup.rs::take_armor` and `entities/stock/items.rs::player_take_armor`. Both only change `Player::slots_used`. Then `weapons/inventory.rs::sync_speed` recomputes `slots_used = SLOTS - free_slots`, so the kevlar weight disappears on the next pickup or drop, and weapon purchases never see it.

Fix: both should adjust `inv.sv.free_slots` and call `weapons::sync_speed`, as the CTB case pickup now does (#59).
