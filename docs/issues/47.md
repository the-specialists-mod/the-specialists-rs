# #47: player_take_health doesn't start the overheal decay timer

- State: closed (completed)
- Labels: bug, integration

- Originally CrunchyMonkies/rust-hlmod-the-specialists#47

## Description

TS `CBasePlayer::TakeHealth` (0xd8760) sets the decay timer (+0x73c) to time + 1 when health goes over max, so `PreThink` (0x908cc) then removes 1 health per second.

`player_take_health` in `crates/server/src/entities/stock/items.rs` doesn't set it. So healthkits, health chargers, door heals and negative `trigger_hurt`s can leave a player above 100 health indefinitely. The #38 work adds a correct local `take_health` in `player/water.rs` that could replace it.
