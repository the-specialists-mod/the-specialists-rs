## Description

`CTSFlag::RespawnFlag` (0x9de58) schedules the home `CTSBriefcase::FlagFall` at +1.0 s. It prints "%s briefcase returned" with the owning team's name (team table at 0x1781c8 + team*0x8c, only when team < 4) via `TSHudMessageAll(0,255,0,4,30)`.

The port's `Flag::think` (`crates/server/src/entities/ts/ctb.rs`) uses `self.contents` as the text, holds it for 8 instead of 30, and calls `go_home(cx, 0.25)`. The 0.25 s delay on the capture path (0x8db9c) is correct.
