## Description

`death_think` (`rules/lifecycle.rs`) waits a fixed 1.2 s for the death animation, because there is
no sequence-finished flag. TS uses `m_fSequenceFinished` (pl+0x78, inferred) to end the dying
state when the animation actually finishes. Track sequence completion on the server from the
studio sequence length and framerate, which also matters in slow motion.
