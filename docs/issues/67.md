## Description

The Steam HL25 client checks in `docs/validation.md` §5/§5.1 are run by hand:
- writing the client cfgs,
- forwarding `SRVCMD` lines to the server's stdin,
- collecting screenshots,
- opening the GameUI through gdb.

Several client bugs only showed up on the Steam client, not on FWGS: #62 (black world), plus three of the four fixed for #23 (server view angles held while a menu is open, click-to-spawn broken after `changelevel`, third person after respawn).

Proposal: a `cargo xtask steam <listen|server-root>` command with the same scenes as `xtask play`, plus `changelevel`, to catch these regressions. It needs Steam running and logged in, and only one copy can run at a time. Launch via `steam-runtime/run.sh ./hl.sh` with `SteamAppId=70`, not `steam -applaunch`, which hangs while the screen is locked.
