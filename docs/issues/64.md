# #64: WorldGun BounceTouch skips the ×0.9 ground damping and uses the wrong slow-motion floor

## Description

`CTSWorldGun::BounceTouch` (0xa0b0c; objdump 0x90b0c) has the same ground branch as `CTSFlag::BounceTouch`: velocity and spin are scaled by ×0.9 when horizontal speed is above 40×`GiveSlowMul()`, and by ×0.7 otherwise (constants at 0xf7f44 / 0xf7f50).

`crates/server/src/weapons/worldgun.rs` differs in three ways:
- It applies only the ×0.7, at or below 40, and nothing above it.
- It then adds a port-only ×0.5 ground friction in `think`.
- For the 3× / 18× / 40× thresholds it uses `fuser1 > 0 ? fuser1 : 1` where TS uses `FixedSlowAmt` (0x990bc, `max(fuser1, 0.01)`).

Note: the port's extra friction works around FWGS not slowing a sliding `MOVETYPE_BOUNCE` entity. Check that before removing it. The CTB case (#59) now uses only TS's damping, so its in-engine behaviour on `ctb_deadheat` tells you whether the workaround is needed.
