# #40: Crosshair ignores the third-person aim point and hides when zoomed in third person

## Description

In TS, `DrawCrosshair` (`0x1004e9f0`) centres the crosshair in third person on the projected end of the view trace (the point `DrawCrosshairID` `0x1004acc0` stores at `0x100d0cd8`). In third person it also clears the scoped flag (`0x1018a704`), so the crosshair lines still draw while zoomed.

The port's `draw_crosshair` (`crates/client/src/hud/weapons.rs`):
- always uses the screen centre,
- hides the lines whenever FOV < 40, even in third person.

The `crosshair_centre` helper added for #5 already computes TS's centre, so the fix is to call it there and add the third-person check.
