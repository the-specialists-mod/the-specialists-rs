## Description

The `TSMBlur` message (byte entindex, byte mode) is decoded and recorded, but nothing is drawn.
In TS, `MotionBlur::Toggle` and the trail manager `MotionBlur_Update` (`0x10029780`, called
from `HUD_CreateEntities`) draw ghost copies with renderfx 17 and `rendercolor.b = 1`. Slow
motion uses this effect (`use_powerup` sends `TsMBlur`), and so do stunts.
