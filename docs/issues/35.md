# #35: Windows mouse code in goldsrc/platform.rs has unsafe blocks without SAFETY comments

## Description

AGENTS.md rule 4 requires a `// SAFETY:` comment on every `unsafe` block. Most blocks in the Windows-only code of `crates/goldsrc/src/platform.rs` have none:
- `sdl::lookup` (Windows version): `GetModuleHandleA`, `GetProcAddress`
- `win::startup`, `activate`, `deactivate`: `SystemParametersInfoA`
- `win::center`: `GetWindowCenterX/Y`
- `win::delta`: `GetCursorPos`, `SetCursorPos`

The Linux clippy run never compiles this code, so the gaps go unnoticed. `cargo clippy --target i686-pc-windows-gnu -p goldsrc --features client` reports 17 undocumented-unsafe warnings.

Fix: add the comments, and run clippy for a Windows target in xtask (or CI).
