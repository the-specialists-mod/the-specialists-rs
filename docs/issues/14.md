## Description

TS has chat votes: `vote map <name>`, `vote stats` and `vote reset` (`PlayerVote` 0x7a1c8). It keeps
per-player vote records at TSGameRules +0x684 (32 × 0x48), tallies at +0xf84..+0x1824, and the
chosen map at +0x1824. When a vote has set the next map, `CHalfLifeMultiplay::Think` (0xcf038)
calls `GoToIntermission`. None of this is ported.
