## Description

Found while working on #95 (checked in `ts_i386.so` and the port; Ghidra addresses):

1. **Pickups by dead players.** `entities/stock/items.rs` refuses pickups by dead players before `MyTouch`. TS's `CItem::ItemTouch` (0xcaf8c) checks only IsPlayer and CanHaveItem, which always returns 1.
2. **Gun weapon bit.** TS sets bit 16 of `pev->weapons` when the gun is added (`CBasePlayerWeapon::AddToPlayer` 0xf1e60; gun id 16 from `CTSGun::GetItemInfo` 0x85dd0). The port's `weapons/mod.rs` `give_gun` never sets it.
3. **Global precaches.** `W_Precache` precaches `item_suit` and others (decomp `global_000f1168.c:98`). `TSPrecache` (0x9f320) precaches `m61_grenade`, `shrapnel` and `ts_flag`. `CWorld::Precache` precaches `common/null.wav` (`CWorld.c:56`). The port does none of these globally (the precache order also affects model and sound indices).
4. **Moves.** `entities/stock/base.rs` `linear_move`/`angular_move` finish at once when the speed is 0, and multiply by `1/travel`. TS's `LinearMove` (0xe3658) and `AngularMove` (0xe386c) have no speed check and divide.
5. **Crushers.** `damage.rs` skips victims with `takedamage` 0, but TS's crushers call `TakeDamage` directly (e.g. `CFuncPlat::Blocked` 0xd2e64).
6. **`func_train` sound keys.** `trains.rs` parses `movesnd`/`stopsnd` as plain ints. TS (0xd1f80) converts them to a 16-bit value and keeps the low byte.
7. **`cycler_weapon`.** TS adds it to the player's Half-Life weapon slots and switches to it. The port only models the TS gun, so it can't be picked up.
8. **A map-placed `weapon_tsgun` that's been picked up** is removed at once. In TS the entity stays, hidden, until the gun is destroyed.
9. **`ParmsChangeLevel`** is a no-op (`server-dll/src/lib.rs`). TS builds the transition list there (0xe87c4). This only matters with save/restore.
