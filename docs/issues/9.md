## Description

TS's `DeathNotice` (0x88f7c) and `TakeDamage` send `svc_director` to HLTV spectators. They use
`MSG_SPEC`, with message id `0x32` (the older `SVC_HLTV` value, not the SDK's 51) and
`DRC_CMD_EVENT`, e.g. `byte 3, short victim, short killer/inflictor, long 0x27`. The port sends
none of these, and the client's `HUD_DirectorEvent` / `CHudSpectator::DirectorMessage` isn't ported.
