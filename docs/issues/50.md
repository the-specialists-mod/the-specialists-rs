# #50: PostThink runs during intermission; TS skips it when the game is over

- State: closed (completed)

- Originally CrunchyMonkies/rust-hlmod-the-specialists#50

## Description

`CBasePlayer::PostThink` (0x91610) returns straight away when `g_fGameOver` is set or the player is dead. So in TS, `ItemPostFrame` (firing, `PlayerUse`) and the tank handling don't run during intermission.

The port's `Player::post_think` (`crates/server/src/player/mod.rs`) calls `drive::post_think`, `weapons::post_think` and `stunt::post_think` without checking `state::with(|g| g.game_over)`, so players can still fire and use things after the map ends.
