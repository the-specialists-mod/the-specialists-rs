## Description

Found while working on #82; checked in both binaries and the port. The server and client must change together.

- **TS client:** for the local player or the in-eye spectated player, it plays the weapon's normal anim set at index \`i2\`, blocks included (\`client.dll\` 0x100433bb..0x10043401).
- **TS server:** sends \`i2\` as an index from 0 to 11 (\`ts_i386.so\` objdump 0x762d7..0x76997, pushed at 0x76daa).
- **Port server:** sends -1 or 10..25 (\`crates/shared/src/weapons/gun.rs\`, \`view_anim\` in the close-combat attack).
- **Port client:** \`crates/client/src/events/misc.rs\` (\`close_combat\`) plays \`i2\` as a raw sequence, and only for the local player's attacks.

Port TS's index choice on the server and the anim-set lookup (plus the in-eye case) on the client, so the original TS client and the port's client both show the right animation. This is noted in \`client-rendering.md\` "Missing pieces".
