## Description

Server differences from \`ts_i386.so\` (Ghidra addresses), found while working on #84:

1. **\`SetDefaultPlayerTeam\` (0xe44ac)** only stores the team name (\`m_szTeamName\`, \`+0xb48\`). The port's \`team_names()\` / \`set_team_list\` (\`crates/server/src/rules/state.rs\`) keep the one listed team; only the \`model\` choice from #84 follows the missing limit.
