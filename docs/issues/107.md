# #107: Server: Server_GetBlendingInterface not exported (server-side bone setup / hitboxes)

## Description

`ts_i386.so` exports `Server_GetBlendingInterface` (objdump 0x93f80). For interface version 1, it returns 1 and fills in the engine's `sv_blending_interface_t` with TS's own `SV_StudioSetupBones`. The engine then uses TS's bone setup for server-side hitboxes and traces against studio models. The port's `libts.so` doesn't export it, so the engine falls back to its built-in bone setup, and player hitboxes on the server can differ from TS (for example TS's split torso/legs blending, which the client ports in `studio.rs`).

Found by comparing the defined function exports of both libraries after #104. The only other TS-only exports are the math helpers `anglemod`, `Length` and `Q_log2`, which no engine calls; also export them, so the export list matches exactly. The Windows `mp.dll` export list (from #95) is also missing `Server_GetBlendingInterface` and `CreateInterface`.
