## Description

TS `CBasePlayer::PlayerUse` (0xd9848):
- For objects without `CanUsedTroughWalls` (vtable slot 3), traces from the eye to the object's centre and refuses if the trace is blocked.
- Plays `common/wpn_select.wav` (volume 0.4, `ATTN_NORM`) on a +use press when an object is found.
- Picks the object with `UTIL_ClampVectorToBox` over objects whose caps include 0x38.
- For continuous users, sets `PFLAG_USING`; on +use release, sends `USE_OFF` to on/off users.

The port's `stock::player_use` (`crates/server/src/entities/stock/mod.rs`):
- has no trace, so buttons can be used through walls,
- plays no sound,
- uses a dot test against the normalised centre instead of the box clamp,
- has no release or `USE_OFF` handling.
