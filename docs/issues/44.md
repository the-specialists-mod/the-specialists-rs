## Description

`goldsrc/src/ext/hud.rs` declares its own `#[repr(C)] EventApi`, with a comment saying bindgen only sees `event_api_s` as opaque. That's no longer true: `goldsrc-sys` now generates the full struct, and `ext/render.rs` uses it.

Two copies of the same table can drift apart. There are also two view-height paths with different fallbacks:
- `ClEngine::local_view_height` returns 28 when the slot is null.
- `render::local_player_viewheight` panics.

Switch `hud.rs` to the bindgen struct and keep a single wrapper.
