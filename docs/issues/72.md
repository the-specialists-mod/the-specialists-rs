## Description

Client differences from TS's \`client.dll\`, found while working on #71 and checked against the port's code:

1. **\`cl_thirdperson\` is acted on every frame.** \`crates/client/src/view.rs\` (\`frame\`, the \`last_thirdperson_cvar\` block) sets \`w.third = tp != 0.0\` whenever the cvar changes. In TS this cvar (\`DAT_100df544\`) is only read by the \`Spectator\` message handler (\`unnamed_1005c2a0.c:7517-7525\`).
2. **\`cl_thirdpersonswitch\` is handled twice.** The same function sets \`w.third = weapon == 0\` directly on a weapon change, skipping the toggle's observer and demo checks. 4. **Time scale is eased twice per frame.** Both \`view::frame\` (\`ease_time_scale\`) and \`hud::frame\` (\`approach_timescale\`) update \`state.time_scale\`. #71 fixed the same problem for FOV. Port TS's single easer and remove the other.
