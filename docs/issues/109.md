## Description

Found while working on #104 (checked in `ts_i386.so` and the port; Ghidra addresses):

1. **`func_pendulum` spawnflag 1.** `Spawn` (0xa67f0) uses `time + 0.1`; the port uses `ltime + 0.1` (`bmodels.rs`).
2. **`func_healthcharger`.** `CWallHealth::Use` (0xc8d08) refuses players without the suit bit; the port doesn't (`items.rs`).
3. **`func_recharge`.** `CRecharge::Recharge` (0xc7234) plays no sound; the port plays one.
4. **`game_text`.**
   - `CGameText::Use` (0xcca2c) never fires its targets, and `KeyValue` (0xcc770) ignores delay/killtarget. The port does both.
   - `CRulePointEntity::Spawn` (0xcc42c) clears `pev->model`; the port doesn't (`maprules.rs`).
5. **`TEAM_MASTERS`.** It's keyed by edict address and never cleared between maps (`maprules.rs`).
6. **Effects removal timing.**
   - `CLightning`/`CLaser::Spawn` (0xbb240) set `SUB_Remove` without a `nextthink`, so the entity is never removed; the port removes it at once.
   - A non-repeatable gibshooter's last gib removes the shooter on the next frame in TS, but at once in the port (`effects.rs`).
7. **`ambient_generic`.** `CAmbientGeneric::Precache` (0xdec90) plays a single-character message; the port requires length > 1 (`sound.rs`).
8. **`env_fade`.** `CFade::Spawn` (0xbd68c) calls `SET_MODEL` unconditionally (`effects.rs`).
9. **Trains.**
   - `func_train`'s `Use` (0xd34d8) doesn't call Activate.
   - TS's `Next`/`Wait`/`Use` sounds use the slow-motion pitch factor (`trains.rs`).
   - `func_tracktrain`'s `UpdateSound` (0xd46bc) uses integer pitch maths and the slow-motion factor (`tracktrain.rs`).
10. **`trigger_camera`.** `Use` (0xe9c08) with a non-player activator falls back to slot 1 (`triggers.rs`).
11. **`info_intermission`.** TS's `Spawn`/`Think` (0xddf80/0xddff8) aren't ported (`stock/mod.rs`).
12. **TS weapon remaps.** `GetWeapon` (0xc95ac and the others) re-picks the id and model on each pickup, and `CTSGroundWeapon::GetWeapon` (0xa2328) has no landed check (`ts/ground.rs`).
13. **`ts_particle` / `ts_emitter`.** `CTSParticle::Spawn` (0x74134) removes itself only when there are too many particles. `ts_emitter`'s `CheckValues` uses `||` (`ts/misc.rs`).
14. **`deadcorpse`.** `CTSDeadCorpse::WaitThink` runs every 0.5 s with a fade, and `TSCreateDeadCorpse` (0x70234) uses rendermode 1 with amount 255 (`ts/misc.rs`).
15. **`Activate` after a restore.** TS runs `Activate` on every entity after a restore (and `ServerActivate` on map start). The port has no hook, so `func_train`, `func_guntarget`, `func_tanklaser` and `env_beam` emulate it from their next think. Add an `Entity::activate` hook and call it where TS does.
