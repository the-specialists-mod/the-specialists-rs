# #49: worldspawn ignores most CWorld::KeyValue/Precache keys (MaxRange→sv_zmax, WaveHeight→sv_wateramp, …)

## Description

TS `CWorld::KeyValue` (0xf4a18) handles:
- `skyname`, `sounds` (CD track)
- `WaveHeight` (`pev->scale = v/8`, sets `sv_wateramp`)
- `MaxRange` (`pev->speed`)
- `chaptertitle` (`netname`), `startdark`, `newunit` (`sv_newunit`), `gametitle`
- `mapteams`, `defaultteam`, `gamemode`, `teammodels`

`CWorld::Precache` (0xf449c) then sets:
- `sv_gravity 800`, `sv_stepsize 18`, `room_type 0`
- `sv_zmax` = `pev->speed`, or 4096 when it's 0 or less
- `v_dark` from spawnflags & 1, `gDisplayTitle` from & 2, `mp_defaultteam` from & 4

The port's `World::key_value` (`crates/server/src/entities/stock/mod.rs`) handles only `skyname`, plus the four TS keys in `rules::world_key_value`. Nothing sets `sv_zmax`, `sv_wateramp`, `sv_stepsize`, `sv_gravity` or `v_dark`.

Several shipped maps set `MaxRange` above 4096 (e.g. `ts_slc` 16384, `ts_awaken` 17096, `the-climb` 100000), so their far geometry may be clipped. About ten maps set `WaveHeight` on worldspawn.
