## Description

TS's client \`FireAkimbo\` (0x1003f090) picks the view animation from the weapon's short anim-set table (\`0x10189d54\`):
- linked shot: \`set[3 + RandomLong(0,2)]\` (\`movswl 0x6(%ecx,%eax,2)\` at 0x1003f3e4);
- \`b1\` set: \`set[22 + RandomLong(0,1)]\` (\`0x2c(%edx,%eax,2)\` at 0x1003f406);
- \`b1\` clear: \`set[24 + RandomLong(0,1)]\` (\`0x30(%ecx,%eax,2)\` at 0x1003f41c).

The port's \`crates/client/src/events/fire.rs\` (akimbo branch) uses \`set[26 + r(0,1)]\` for a linked shot, \`set[24 + …]\` for \`b1\` set, and \`set[22 + …]\` for \`b1\` clear. So linked shots use the wrong animations and the two single-hand cases are swapped. Found while working on #11.
