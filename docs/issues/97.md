## Description

Found while working on #89 (checked in `ts_i386.so` and the port; Ghidra addresses):

1. **Impulses.** `ImpulseCommands` (0xdb780) handles impulse 201 (spray) and calls `CheatImpulseCommands` (0xdb9e4); the port has neither (`player/player_use.rs` `impulse_commands`).
2. **`use <item>`.** `ClientCommand` (0xad838) handles `use <item>` (`SelectItem`); the port has no handler anywhere in `crates/server/src`.
3. **Train message order.** `Train` goes out with `HideWeapon`, before TSHealth/TSArmor; TS sends it after TSArmor (`CBasePlayer::UpdateClientData` 0x91d00). The port's send is in `drive.rs`.
4. **ChangeLevel.** `ChangeLevel` doesn't run `CTSGameRules::Init` (0x77d6c). This only affects the frames between the `changelevel` and the new map loading.
5. **`game_player_team`.** It waits until the activating player's think returns; TS changes the team immediately. Fixing this needs entity dispatch changes.
6. **`deathmatch 0`.** With `deathmatch 0`, TS installs `CHalfLifeRules` (0xde6fc, single-player and co-op rules). The port still runs the multiplayer rules.
