## Description

Two remaining differences between TS's \`AddToFullPack\` (0xaf180) and \`crates/server/src/net.rs\`, found while working on #70:

1. **\`spectator\`.** TS stores \`flags & 0x4000000\` (objdump 0x9f77c–0x9f782: \`and \$0x4000000\`, store to state +0xb0). \`delta.lst:190\` gives \`spectator\` 1 bit, so the client always receives 0. The port sends 0 or 1 (\`(v.flags & FL_SPECTATOR != 0) as i32\`), so clients see spectators differently from TS. Check what the client (pmove/prediction, spectator code) does with the field before matching TS.
2. **Empty model.** TS only tests \`pStringBase + model == NULL\`, which never fails. The port also skips entities whose model string is empty. Check which entities this affects (for example, entities with no model but visible effects) and match TS.
