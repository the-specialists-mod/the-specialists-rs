# #28: "timeleft" chat line is not broadcast

- Labels: bug, integration

## Description

In TS, `Host_Say` (0xad02c, `global_000ab05c.c` around line 756) prints "Time left: m:ss" to the sender, and still broadcasts the original chat line: the timeleft branch never clears the broadcast flag.

The port (`host_say` in `crates/server/src/rules/commands.rs`) sends only the time-left text to the sender and drops the chat line, so other players never see it.

Fix: send the time-left line to the sender, then fall through to the normal broadcast.

## Comment by Azerothian on 2026-10-10

Closed as not a bug. In the disassembly of `ts_i386.so`, both exits of `Host_Say`'s timeleft branch jump to 0xad4dc, which clears the broadcast flag, the same place a handled vote ends up. So TS also only replies to the sender and logs the line; it never broadcasts it. The port already behaved this way. Commit 02e722e adds a comment and a note in `docs/implementation/rules.md` so nobody changes it later.
