# #59: CTB pickup, drop and capture details differ from TS (messages, sound, log, TSFlag, throw)

## Description

Three differences in `crates/server/src/entities/ts/ctb.rs`, all checked against the decomp:

1. **Pickup.** `CBasePlayer::TakeFlag` (0x93830) prints "%s picked up a briefcase containing %s!" via `TSHudMessageAll(0,255,0,4,30)`, only when the taker isn't the case's last holder (`s_flag_status` +0x10, pl+0x7e0, which travels with the case). It plays `items/gunpickup2.wav` (CHAN 3, vol 1, attn 0.8) and logs `"%s<%i><%s><%i>" triggered "aquired_briefcase" (contents "%s")`. The port's `Flag::player_take_flag` / `take_flag` uses effect 8, always prints, plays no sound, and leaves the contents off the log. The drop log in `DropFlag` (0x9334c) also has `(contents "%s")`.
2. **Extra `TSFlag` 0.** TS sends `TSFlag` state 0 only from `CTSBriefcase::FlagFall` (0x8da00). `CBasePlayer::DropFlag(true)` (0x9334c, capture) and the owner-return branch of `CTSFlag::PlayerTakeFlag` (0x9e330) send nothing. The port's `drop_flag` (captured branch) and the `player_take_flag` owner-return branch call `send_flag(0, …)` immediately, so the case shows as home before it reappears.
3. **Throw.** `CBasePlayer::DropFlag(false)` (0x9334c) creates the case at eye + forward×16.
   - While alive it is thrown along `v_angle` at speed (90 − pitch)×2.
   - When dead it gets random angles (pitch −60..60, yaw −180..180) and speed 60..160.
   - Either way it gets an upward component of speed×0.33.

   The port's `drop_flag` puts it at the player's origin with the player's velocity.

Related: #57 (timed return) and #27 (CTB untested in-engine).

## Comment by Azerothian on 2026-10-10

A fourth difference: the dropped case never runs `CTSFlag::Fall`.

`CTSFlag::Spawn` sets the think to `CTSFlag::Fall` (0x9df10, decomp `CTSFlag.c:89`), which runs every 0.1 s:
- **Landed and slow:** when the case is on the ground and moving slower than three times its first virtual value, it plays `items/weapondrop1.wav` (channel 6, vol 1, attn 0.8, pitch 100, slow-mo 0.5), zeroes pitch and roll, and calls `OnGround`.
- **Otherwise:** it traces `origin → origin + velocity·0.1`. If the hit entity's first virtual returns 0 and its health ≤ |vel|·30, it calls `TraceAttack(pev, |vel|·30·0.001, vel, &tr, 0x1080)`, then `ApplyMultiDamage(pev, pev)` (0x9e18a). That's the same as `CTSWorldGun::Fall`; in the port it would go through `damage::apply` with `.traced()`.

The port's `Flag::think` (around line 241) only does the 20 s return on a 0.5 s think. So a thrown or dropped case never breaks glass and makes no landing sound.
